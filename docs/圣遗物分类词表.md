> 本文由数据层脚本生成（2026-09-27），与 `src/data.js` 的 `APP_VERSION` 2026.09.26（2+2 任选池改造后）口径一致。

## 一、模型：两层分工

套装定位不再用一维平铺词（输出 / 副C / 辅助 / 增伤 …），改为**两层**：

- **大类（必须选，可多选）**：表示这套圣遗物「配给谁、干哪一路活」，共 4 个取值；
  一套可以同时属于多个大类（例：千岩牢固 = 辅助 + 生存）。
- **关键词（可选，可多选）**：表示在这条路上的**具体需求**，共 22 个取值。

三条硬规则：

1. **关键词不绑大类**，可以跨大类自由组合：`辅助 + 攻击` = 给队友加攻击，`输出 + 精通` = 需要精通的输出；
2. **同一个关键词在不同大类下含义不同**：`输出·攻击` = 装备者自己要攻击面板，`辅助·攻击` = 给队友加攻击；
3. **受益方（自身 / 队友 / 敌人）不进展示词表**，只保留在数据层（`pos2` / `pos4` 的判定依据里）。

展示格式：`大类｜关键词`，同类多个值用 `·` 相连，例如 `输出·辅助｜攻击·剧变反应`。
