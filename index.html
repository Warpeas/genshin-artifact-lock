「恢复内置默认库」＝用内置默认库覆盖本机存档、清除你的全部自定义修改，相当于一次硬刷新；浏览器普通「刷新」只重载页面、不会清本地存档，所以旧数据 / 乱码会一直留着。

关于数据

  • 内置 0 个角色、0 个套装，整理自社区常见推荐，随版本变动请自行校正。
  • 「主推 / 备选」权重：主推 = 1.0，备选 = 0.5；主词条优先级 1/2/3 权重 = 1.0 / 0.5 / 0.25。
  • 建议保留件数 = 以该主词条为最优解的角色数（同一角色多套配装不重复计数），区间 1–4。
  • 2+2 配装对单套的件数需求更低，汇总时按 0.6 系数折算。
  • 主词条 / 副词条需求按配装组分别保存：同一角色换套装时可以有不同的词条需求。

编辑角色

使用说明

三步走

  1. ① 角色配置：勾选你实际要养的角色。点卡片可改套装、主词条优先级和副词条排序；主词条 / 副词条都越靠前优先级越高，副词条还能点 ☆ 标成 ★必须。 一个角色可以有多组配装（4件套 / 2+2），每组的词条需求分开保存；新增配装组时会默认复制当前组的词条，也可以从别组一键复制。
  2. ② 锁定方案：每个套装直接给出「游戏内锁定方案」——把该套装下所有角色的需求聚类合并成 ≤3 个预设， 每个预设逐个部位列出主要属性、★必须副词条、候选副词条与「包含任意 N 条」。照着填进游戏即可。
  3. ③ 副词条规则：给出分档判定 + 胚子评分器，解决「主词条对了但副词条能不能留」。
  4. ④ 数据管理 → 套装管理（浮窗）：点「打开套装管理」增删套装、改 2 件套说明、上下移排序；内置套装只是「隐藏」，可随时恢复。

怎么看方案

  • 方案 N：由需求相近的角色合并而来，标题写明「供谁使用」。同一套装的多个方案在锁定界面共同生效（彼此是「或」的关系）。
  • ✂️ 手动合并：某套装的需求分组超过 3 个时会出现该面板，默认按相似度自动归入，可把任意分组改到方案 1/2/3；改动会保存，「重置为自动合并」一键还原。
  • ★必须：金色词条，这件圣遗物必须有它，否则不锁定。来自组内全体角色都勾选了「必选」的副词条（在角色抽屉里点 ☆ 设置），最多 2 个。
  • 包含任意 N 条：候选池里命中任意 N 条即锁定，★必须的词条也计入这 N 条。
  • 勾选工具栏「显示详细件数」可展开每套的建议保留件数与需求来源；不勾选时页面只显示可直接照搬的锁定方案。

注意

  • 花和羽毛主词条固定，游戏内只能设追加属性，因此这两个部位对副词条要求最严。
  • 空之杯的元素伤杯掉率极低，算法已自动放宽该部位要求，避免漏锁。
  • 副词条不可能与同部位主词条相同，方案里已自动剔除这类无效勾选。
  • 数据存在本机浏览器，换设备用「数据管理 → 导出 JSON」迁移。
