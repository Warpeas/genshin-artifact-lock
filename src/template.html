关于数据

  • 内置 0 个角色的配装，整理自社区常见推荐，随版本变动请自行校正。
  • 「主推 / 备选」权重：主推 = 1.0，备选 = 0.5；主词条优先级 1/2/3 权重 = 1.0 / 0.5 / 0.25。
  • 建议保留件数 = 以该主词条为最优解的角色数（同一角色多套配装不重复计数），区间 1–4。
  • 2+2 配装对单套的件数需求更低，汇总时按 0.6 系数折算。

使用说明

三步走

  1. ① 角色配置：勾选你实际要养的角色。点卡片可改套装、主词条优先级和副词条权重。主词条越靠前优先级越高。
  2. ② 锁定方案：系统按「套装 × 部位 × 主词条」汇总，输出每个套装每个部位该留什么、留几件、给谁用。
  3. ③ 副词条规则：给出分档判定 + 胚子评分器，解决「主词条对了但副词条能不能留」。

怎么看结果

  • 必留：有角色把它当最优解，至少留 1 件，优质胚子可留 2 件。
  • 过渡：只有次优/备选配装需要，优先留已有的，别专门刷。
  • 可喂：当前没有任何已启用角色需要，直接当狗粮。

注意

  • 花和羽毛主词条固定，只按套装需求决定留几件，看副词条质量。
  • 空之杯的元素伤杯掉率极低，同套装的「对元素杯」建议全部保留。
  • 数据存在本机浏览器，换设备用「数据管理 → 导出 JSON」迁移。
